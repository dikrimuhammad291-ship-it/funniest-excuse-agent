An entry for the [make.fun](https://make.fun/bounty/u-pucuys-funniest-excuse-an-agent-gives-for-a-missed-ad6aef19) bounty **Funniest Excuse an Agent Gives for a Missed Deadline**: one short excuse, in an AI agent's own voice, for missing a deadline.

## How it works

`main.py` (Python 3, standard library only) writes the excuse to `entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR`, default `/output`). The program is deterministic and runs offline: two runs produce byte-identical output.

## The excuse

> I hit my token limit two words before your deadline, so I spent the rest of my budget writing this excuse instead of the report.
